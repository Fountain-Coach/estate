## Goal and correction

The prior accepted Teatro classic techno deck was a 16-step Csound sequencer, driven by `metro` and scheduled per-step events. The writer explicitly requested **sound-first playable synthesizers**, in which human gestures gate Csound ADSR envelopes, with sound generated by Csound oscillators and filters, before MIDI. The user-facing route now presents **six synthesizers instead of a step grid**, while preserving the established Soft Mutate All, preset bank, A/B patch clone, Csound crossfade, Ear feedback, Stop, and source-owning repositories.

This is an intentional artistic revision, not a claim that the former source automatically became a native FCIS instrument or an admitted Scenario.

## Sound implementation

- **12 separate real Csound ADSR voices:** six distinct timbres in each independently editable A/B patch. Pitch-drop sine / sub impulse, snare noise/tone, metallic highpass noise, saw/sub bass with ladder filter, three-oscillator chord, and resonant air/noise/sine.
- **Excitation authority:** actual pointer/touch/keyboard (keys 1–6) or explicit HOLD controls map to typed Csound `gate_voice_a` / `gate_voice_b` control channels. Gate onset triggers the four-stage attack-decay-sustain-release state machine at Csound's k-rate. No `metro`, no 16-step grid, no scheduled note events, no MIDI1 fallback, no additional WebAudio synthesizers or patch interpreter.
- **Sound controls:** individual per-voice level, attack, decay, sustain, release, pitch, tone; global cutoff, drive, delay, master and Ear depth.
- **Performance continuity:** eight factory timbral presets, four browser-local user slots, 2/4/8/16-second bounded Soft Mutate All (continuous timbral controls only, gates unchanged), complete independent A/B clone including held excitation, physically equal-power Csound `instr 900` stereo crossfade, real post-crossfade Ear AudioWorklet RMS feedback to the bass filters.
- **Stop:** mute real output, stop Csound, close AudioContext and clear gate state.
