# Three-publication estate boundary

- The only public editorial front doors are Fountain Coach, First Reading, Teatro.
- Each domain has one independent GitHub source owner; this registry does not edit their content.
- Supporting technical, legal, reference and personal sites remain reachable outside primary navigation.
- Status is mandatory legal-footer transparency, never header rail.
- Governance is the complete normative source, not the rejected Constitution anthology.
- MIDI2 implementation/spec evidence is distinct from MIDI Association certification.
- Old Book of Reframe is historical reference, not a Linotype release.
- Never retire Hetzner Caddy merely by retiring the Hetzner Git transport.
- Never force-push, overwrite owners from the derived estate or claim public deployment from Git pushes.


## Hierarchical edition invariant

- `/` **is** the editions catalogue, not a volume or essay index.
- Every domain's estate rail targets the **edition itself**: Fountain Coach
  `/editions/essays/`, First Reading's accepted Linotype edition, Teatro's
  own performance domain.
- Nested essays are complete separately paginated works with independent
  URL and reading state. The source essay routes remain immutable.
- Other portfolio domains remain governed references or legal/technical
  destinations, not fabricated chapters.
- The staged three-front release v3 is not a public production deployment.


## Teatro source-book audio boundary

- Teatro's root and estate rail enter /editions/first-hearing/, not Stage.
- Source text: Fountain-Coach/fountain.coach, complete verified 22-paragraph
  essay and original plate; do not create synthetic filler.
- Soundstage: /editions/stage/ retains compiled browser-Csound runtime and
  returns to the book.
- Satzfunk Hear: author-approved released recording only; absent media is
  explicitly reported, not silently generated from text.
- Stage playback is user-activated, not proof of a spoken edition or
  a Reframe/MIDI2/Ear performance witness.

## Estate grid invariant

- Fountain Coach root and `/editions/` display an **actual repeating grid**
  with four occupied cells (one authentic logo and three source-owned covers)
  plus visibly empty, dashed slots. Empty cells are inert and aria-hidden,
  never fabricated publications or unassigned clickable links.
- Preserve the formerly detailed catalogue at `/editions/catalogue/` and
  every full essay manuscript/nested route; MIDI2 Instruments stays intact.
- The estate's WLAN-only renderer remaps the three root cover links to
  neighboring preview ports, never claiming public availability.
- Production remains a separate explicitly governed deployment operation.

**rounded square** of the same dimensions and border radius as each empty

## Complete owned-estate source contract (15 October 2026)

The canonical machine-readable owner/route/deployment reconciliation is under
`inventory/`, governed by `inventory/CONTRACT.md`. Do **not** infer an estate
inventory from a Bookshelf selection, published collection covers, or a locally
successful landing-page test. The inventory discovers the registered domain
owners by their actual GitHub remotes, emits every Git-tracked HTML source
route and link, respects delegated hosting boundaries, and stores independent
HTTPS readback separately from candidate Git state. The current public
fountain.coach root matches its historical baseline, not the latest two-cover
landing source; missing cross-domain links are explicitly diagnosed.

`npm run check` must fail when the source inventory becomes stale. Use
`npm run inventory:build` to regenerate it after a source or ownership change,
then `npm run inventory:probe` to refresh bounded public HTTPS readback.
A pass does not mean production was updated or every remote URL was crawled.
No GitHub Actions, no automated push, no DNS/Caddy changes are authorized by
these operations. Record source versus public mismatches before any publishing
promotion or UI taxonomy changes.

## ADR 001 — Local Ubuntu disaster-recovery rehearsal

Consult [ADR 001](docs/decisions/001-local-ubuntu-off-provider-tunnel-recovery.md) before cold-restore, DNS migration, tunnel creation or recovery-host work. The existing WLAN Ubuntu machine is the planned isolated recovery origin; a temporary outbound tunnel is the proposed external witness. The ADR does not authorize mutation of live DNS, Caddy, Cloudflare accounts, existing WLAN staging, credentials or published routes.

Restore exact last-published revisions and complete content/assets from owner repositories, never default to Git main or an incomplete Bookshelf. Protect every domain, including delegated Solstice, Teatro the tool and technical/governance material. Keep private Store recovery independent. Fail closed if sources, full release identities or security authority are absent. Canonical failover requires a separate owner-approved, verified and reversible operation.
