# Three-publication estate boundary

- The only public editorial front doors are Fountain Coach, First Reading, Teatro.
- Each domain has one independent GitHub source owner; this registry does not edit their content.
- Supporting technical, legal, reference and personal sites remain reachable outside primary navigation.
- Status is mandatory legal-footer transparency, never header rail.
- Governance is the complete normative source, not the rejected Constitution anthology.
- MIDI2 implementation/spec evidence is distinct from MIDI Association certification.
- Old Book of Reframe is historical reference, not a Linotype release.
- Never retire Hetzner Caddy merely by retiring the Hetzner Git transport.
- Never force-push, overwrite owners from the derived estate or claim public deployment from Git pushes.


## Hierarchical edition invariant

- `/` **is** the editions catalogue, not a volume or essay index.
- Every domain's estate rail targets the **edition itself**: Fountain Coach
  `/editions/essays/`, First Reading's accepted Linotype edition, Teatro's
  own performance domain.
- Nested essays are complete separately paginated works with independent
  URL and reading state. The source essay routes remain immutable.
- Other portfolio domains remain governed references or legal/technical
  destinations, not fabricated chapters.
- The staged three-front release v3 is not a public production deployment.


## Teatro source-book audio boundary

- Teatro's root and estate rail enter /editions/first-hearing/, not Stage.
- Source text: Fountain-Coach/fountain.coach, complete verified 22-paragraph
  essay and original plate; do not create synthetic filler.
- Soundstage: /editions/stage/ retains compiled browser-Csound runtime and
  returns to the book.
- Satzfunk Hear: author-approved released recording only; absent media is
  explicitly reported, not silently generated from text.
- Stage playback is user-activated, not proof of a spoken edition or
  a Reframe/MIDI2/Ear performance witness.
